# Security policy

## Reporting a problem

**Please don't report security problems in a public issue.**

Report them privately through GitHub: open the repository's **Security** tab
and click **Report a vulnerability**. Only you and I can see the report.

Please include:

- what the problem is and what someone could do with it
- the steps to make it happen
- the version you found it in

## Supported versions

Only the **latest release** of each project gets fixes. If you're on an
older version, update first and check whether the problem is still there.

## What to expect

These are hobby projects, maintained on a **best-effort basis, with no
timeline**. I'll read every report, but I can't promise when I'll reply or
when a fix will ship.

The code is AI-generated (see each project's README), which is another
reason to report anything that looks wrong.
